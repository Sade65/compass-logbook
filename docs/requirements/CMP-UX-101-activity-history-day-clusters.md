# CMP-UX-101 — Activity History Day Clusters

## Goal
Make historical Activity Log review easier to scan than one long mixed-date table.

## Requirements
- Group previous activities under a visible day/date heading.
- Preserve reverse-chronological session order inside each day while retaining stable activity ordinals.
- Show five historical days by default.
- `Show 5 older activity days` reveals another five day clusters.
- Keep the existing detailed record/table representation; a richer card-based day navigator is a separate follow-up requirement.
