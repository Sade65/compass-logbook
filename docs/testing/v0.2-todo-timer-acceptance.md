# v0.2 Todo & Timer Acceptance Test

Run these checks locally before marking the v0.2 requirements Done.

## CMP-FIX-001 — Persistent Timer Recovery

### T-001 Live counter
1. Start a Todo.
2. Leave the page untouched for at least 20 seconds.
3. Confirm the visible elapsed time increases without manual refresh.

### T-002 Browser reload
1. Start a Todo and note the clock time.
2. Reload the browser page.
3. Confirm the same Todo is still running and elapsed time is correct.

### T-003 Streamlit restart
1. Start a Todo.
2. Stop Streamlit with `Ctrl+C` in the terminal.
3. Wait at least 30 seconds.
4. Restart with `python -m streamlit run app.py`.
5. Confirm the same Todo is still running and the offline interval is included.

### T-004 Stop is durable
1. Stop an active timer.
2. Before saving the post-session form, reload the page or restart Streamlit.
3. Confirm the stopped session is still waiting to be reviewed.
4. Confirm its duration did not grow after Stop.

## CMP-FIX-036 — Todo / Session State Synchronization

### T-005 Keep open
1. Start an open Todo.
2. Stop it.
3. Select `No, keep open` and save.
4. Confirm Todo status is `open` and nothing is running.

### T-006 Complete then restart work
1. Start a Todo, stop it, choose `Yes, mark done`, and save.
2. Confirm Todo status is `done`.
3. Start the same Todo again.
4. Confirm it automatically changes to `open` while the new session runs.

## CMP-FEAT-035 — Per-Session Activity Classification

### T-007 Multiple activity types
1. Start the same Todo as `Admin`, stop, keep open, and save.
2. Start it again as `Development / Coding`, stop, and save.
3. Confirm two activity-log rows share the same `todo_id` but have their respective activity categories.

## Todo UX

### T-008 Create feedback
1. Add a Todo.
2. Confirm the form clears and `Todo added ✓` is shown.
3. Confirm the newly created Todo appears first.
4. Confirm the card shows `added HH:MM`.

### T-009 Copy selected Todo text
1. Select a Todo title with the mouse.
2. Press `Cmd+C`.
3. Confirm text copies normally and the Streamlit Clear Cache dialog does not appear.
